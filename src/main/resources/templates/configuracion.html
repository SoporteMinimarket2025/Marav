Roles de usuario

Los permisos dependen del rol asignado.

ADMIN

Administrador

Tiene acceso administrativo al negocio y puede gestionar la información principal.

  • Gestionar productos
  • Gestionar clientes y proveedores
  • Crear empleados
  • Registrar ventas
  • Gestionar caja y devoluciones
EMPLEADO

Empleado

Puede consultar información y realizar las operaciones permitidas por el negocio.

  • Consultar productos
  • Consultar clientes
  • Consultar proveedores
  • Realizar operaciones permitidas
  • Consultar información del negocio

Recomendaciones

  • Registra primero la información básica antes de realizar ventas.
  • Mantén actualizado el inventario.
  • Verifica los datos del cliente antes de registrar una venta a crédito.
  • Revisa las facturas después de cada venta.
  • Utiliza el buscador de cada módulo para encontrar información rápidamente.
  • Si eres empleado y una opción no aparece, puede tratarse de una restricción de permisos.
